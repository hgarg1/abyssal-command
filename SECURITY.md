# Security Policy

## Supported version

Security fixes are applied to the latest version on the `main` branch.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's **Report a vulnerability** option in the repository Security tab to submit a private advisory.

Include:

- The affected route, component, or dependency
- Reproduction steps or a minimal proof of concept
- Expected impact
- Any suggested mitigation

You should receive an initial acknowledgement within seven days. Confirmed issues will be prioritized according to exploitability and impact, and coordinated disclosure will be arranged before details are made public.

## Demo environment

The public deployment contains simulated mission data only. Do not submit secrets, personal data, or sensitive operational information through commands or mission payloads.
